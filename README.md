# omarchy-badges

"Powered by Omarchy" 88x31 buttons, one for each of the 22 default [Omarchy](https://omarchy.org) themes.
Each has a 3s still, then a shine that sweeps across the wordmark.

Every size is a nearest-neighbour scale of the 88x31 original: `badges/<size>/<theme>.gif`, with a still of the first frame alongside it as `.png`.
Sizes are 88x31, 176x62, 264x93, 352x124, 880x310.

```html
<a href="https://omarchy.org"><img src="badges/88x31/tokyo-night.gif" width="88" height="31" alt="powered by omarchy"></a>
```

Scale them up with `image-rendering: pixelated` so they stay crisp.

## Rebuilding

```sh
python3 build.py           # render badges/ from themes.json
python3 build.py --fetch   # refresh themes.json from omarchy.org first
```

Needs Python 3 and ImageMagick 7. Colours come from omarchy.org's per-theme CSS variables, so every badge matches the site in that theme.
`logo.txt` is `/usr/share/omarchy/logo.svg` thresholded to an 81x19 grid.
